# LeadScroll brand asset

`leadscroll-mark.svg` is the existing user-supplied logo's vector version, copied
unchanged from `gigs/2026-09-24-browser-intake-sdk/artifacts/brand/lead-scroll-mark.svg`
in the project container (original assets supplied 2026-09-28).

The SVG palette is navy #161E27, orange #FD6600, and white #FFFFFF. The sidebar,
sign-in screen and favicon reuse this mark. CSS keeps the exact brand colors as
tokens, while interactive controls use a quieter apricot derived from the orange.
Original PNGs and other lockups remain preserved in the source gig.
